Command Processing Flow
When you type a command and press Enter, the system processes it through these steps:
  1. Input Processing: Command is captured on Enter keypress
  2. Thinking Mode: Shows spinning animation while processing
  3. Tool Detection: AI identifies needed tools like [themes], [documents], [changeTheme:girly]
  4. Tool Execution: Tools are executed to gather data or perform actions
  5. Response Generation: AI generates a helpful response with proper formatting
  6. Display: Response appears below the input with markdown rendering
Available Tools
The AI can use these tools to help users:
  • [themes] - Get list of available themes
  • [documents] - Get user's recent documents
  • [settings] - Get current app settings
  • [changeTheme:themeName] - Change app theme (e.g., girly, dark, forest)
Example Interactions
User: "Change the theme to look more girly"

AI Response:

Perfect! I've changed your theme to "Pretty Pink" which has a lovely girly aesthetic with soft pink colors. The theme has been applied and saved to your settings.

Key Features
  • ✅ No Send Button: Enter key triggers processing
  • ✅ Thinking Animation: Shows processing state with spinning icon
  • ✅ Tool Integration: AI can call functions to get data or perform actions
  • ✅ Proper Formatting: Responses render markdown without ** issues
  • ✅ Theme Integration: Matches current theme colors and styles
  • ✅ Responsive Design: Adapts to different screen sizes
  • ✅ Context Aware: Only shows when AI is enabled in settings
